# 后端报价覆盖范围引文校验

2026-11-19，需求为[优化方案](procurement-agent-optimization-plan.md)第一轮步骤4。用户明确授权跳过上一轮控制题解析失败的修复，进入后端校验；PR39的提示词结果和失败继续保留，不改为已验收。本轮沿用#34及本地优化交接，不新建评测模块事项。

## 后端行为

只修改软件 `price_basis` 的提交校验，原提示词、制度、工具及解析器不变。引文必须逐字存在，且支持所提交的单席/全部席位覆盖范围。仅有元/月或申请席位数量不能证明覆盖范围；否定、疑问及冲突范围不能用于计算总额。

校验支持显式每席/全部席位价格、`120元/席/月`、明确口径标签及否定另一口径后的正面报价。检查引文在原文中的上下文，区分报价范围不明确与税费/用途等其他事项的疑问。无法核对时返回具体 `price_basis` 错误及更正/省略指引，不自动猜值或静默删除；Agent可同时从materials/evidence省略未知字段，再提交其他已知材料。

原规则解析器可能从否定表述中错误确认范围，后端不会把这种无证据的值强制锁定；已确认字段的范围同样使用本校验核对来源。其余字段仍保留原有约束，parser自身未修改。该校验是有界规则，不宣称能判定所有自然语言报价表达；未识别表达留待澄清。
